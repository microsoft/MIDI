This is the main namespace. It holds the types almost every application uses: `MidiSession` and `MidiEndpointConnection` for connecting to endpoints and sending and receiving messages, the message types, `MidiClock` for timestamps, and `MidiGroup` and `MidiChannel`.

To find the endpoints you can connect to, see the [Enumeration]({{ site.baseurl }}/sdk-reference/Enumeration/) namespace.
