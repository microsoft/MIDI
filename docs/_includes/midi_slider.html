Windows MIDI Services is Here

Everyone on supported Windows 11 releases (25H2 and later) who has updates enabled has the new Windows MIDI Services infrastructure already in Windows. Windows MIDI Services brings enhanced MIDI 1.0 support (including multi-client) to your PC, and enables the MIDI 2.0 infrastructure including a new USB class driver.

For developers, the API is currently in preview and may be downloaded from GitHub. For customers, the tools and preview transports, including RTP-MIDI, BLE MIDI, Network MIDI, and MIDI 1.0 loopbacks, are available for you via the GitHub release.
