  1. Timecode calculator, with a running tape of what you did. Frame rates: 23.976, 24, 25, 29.97 (drop and non-drop), 30, 50, 59.94 (drop and non-drop) and 60. Drop frame is written with a semicolon, the way editors write it. Typing fills from the right, so "1:20" is one second and twenty frames, as in the MIDI Clock app.
  2. Convert a timecode to frames, real time, samples and bars. "Same moment at" moves it to another frame rate and shows what's left over. This needs more frame rates than MIDI Time Code carries, so the calculator gets its own timecode math, tested against the shared MIDI Time Code code for the four rates they have in common.
  3. Samples and buffers. Samples to time and bars, and one buffer's length at common sizes. The row for the session sample rate is lit. It says plainly that this is only the buffer, so nobody reads it as their total latency.
