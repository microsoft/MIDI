  1. Note pitch. Type a note and cents, or a frequency, and get the Note On's Pitch 7.9 attribute and the Pitch 7.25 per-note controller. The bit picture shows where the semitone ends and the fraction starts. "Widened to 7.25" pads with zeros, as the bit scaling spec says to for pitch, so a receiver that converts gets the same pitch you sent. Paste a hex value into either row to go the other way.
  2. Pitch bend in both protocols, from a range and an amount. Shows how much the 14-bit MIDI 1.0 value loses, and the RPN 0 messages that set the range.
  3. Value scaling, with the spec's min-center-max method by default and zero-extension as the other choice. Typing in any row recalculates the rest, so it works for downscaling too.
  4. UMP timing: Jitter Reduction timestamps and the Delta Clockstamps used in MIDI Clip Files, at the session tempo.
  5. Decode UMP words uses the same decoder as the Windows MIDI Monitor and Patchbay, with each field colored over its bits. Group and channel show both the number on the wire and the one people read. Build a message goes the other way. The manufacturer ID converter is here too, because it's needed when you hand-build SysEx 8.
