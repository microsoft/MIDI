  1. Six pages in a left navigation pane, plus History at the bottom. The pane folds to icons in a narrow window. The app opens on the page you used last.
  2. Session values. Tempo, meter, sample rate, tuning reference and frame rate, set once and used by every page. Tap tempo, the beat calculator and Measure MIDI Clock can each write their answer here. They're saved between runs. Reset puts back 120 BPM, 4/4, 48 kHz, A3 = 440 Hz, 24 fps.
  3. Tap tempo with the mouse, the T key or the spacebar, or with any note from a MIDI input (the Listen to MIDI link picks the endpoint). Uses the MIDI Clock app's tap tempo code. "Steady within" tells you if the taps were even enough to trust.
  4. Beat calculator, modeled on the one Cubase users keep asking Steinberg to bring back. Three questions, one form: the tempo from bars and a length, the length from bars and a tempo, or how many bars fit. The length takes time, samples or timecode, so you can paste a sample count straight from an audio editor.
  5. Tempo change. Speed, new length and the pitch change you'd hear if you just sped up the audio. Type a target tempo or a percentage; the other one updates.
  6. Note lengths for setting a delay, an LFO or a gate by hand. Ticks uses 960 per quarter note, the same as the Windows MIDI Sequencer, and can be changed in Settings.
  7. Measure MIDI Clock builds on the clock follower code the tools already share. It shows start, stop and song position as well, so it doubles as a quick check that a clock source is sending what you think it is.
