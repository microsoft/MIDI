  1. Note to frequency. The note box takes the same text every Windows MIDI tool takes ("A3", "Bb1", "F♯0", "69"), using the shared note-name code. The speaker button plays the note on the Windows MIDI Sound Module or an endpoint you pick, so you can check it by ear.
  2. Frequency to note, like a tuner you type into. The link jumps to the MIDI 2.0 page with this pitch already filled in, since a MIDI 2.0 note can carry that exact pitch.
  3. Interval: name, semitones, cents and ratio, with how far equal temperament is from the pure interval. Works in both directions: pick two notes, or one note and a distance.
  4. Note table for one octave at a time, using the session tuning reference. The temperament list starts with equal temperament only; see the open questions on the index page.
