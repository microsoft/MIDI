# Velocity sweep.
#
# One note, one instrument, velocity descending. Church organ because it sustains without
# decaying, so the RMS of each note is a stable measure of level rather than a function of
# where in the decay the window happens to land.
#
# Descending so the first note is the loudest, which makes onset detection reliable; the rest
# are found from the known 2 second interval. One second gaps so release tails do not bleed
# into the next measurement window.
#
# Channel volume at maximum so quiet notes are not buried, and so the channel volume concave
# transform is at unity and cannot interact with the velocity curve being measured.

program  0.0  0 0 0 19
cc       0.0  0 7 127

note     0.5  0 60 127 1.0
note     2.5  0 60 112 1.0
note     4.5  0 60  96 1.0
note     6.5  0 60  80 1.0
note     8.5  0 60  64 1.0
note    10.5  0 60  48 1.0
note    12.5  0 60  32 1.0
note    14.5  0 60  24 1.0
note    16.5  0 60  16 1.0
note    18.5  0 60   8 1.0
note    20.5  0 60   1 1.0
