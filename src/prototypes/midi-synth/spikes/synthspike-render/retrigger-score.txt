# Rapid retrigger of the same notes, which is what an arpeggiator at a high rate produces.
#
# The DLS Level 1 default is that a second note on of the same note kills the first. If that kill
# is instantaneous rather than a fast fade, it cuts the waveform mid cycle and clicks.

note  0.74 0 60 110 0.50
note  0.80 0 60 110 0.50
note  0.86 0 60 110 0.50
note  0.92 0 60 110 0.50
note  0.98 0 60 110 0.50
