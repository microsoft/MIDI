Windows MIDI Settings, Configurations window comps

A window for everything people do with whole configurations: switch, back up, restore, share with another PC, and import. These are HTML: open any page in a browser, or run capture.ps1 for pictures in shots and check.ps1 for a layout check. They are pictures of the app, not the app. No product code has changed.

1. Opening the window
A Configurations button in the pinned group on the right of the toolbar, and a slimmer card in Global MIDI settings.
2. Configurations
The one in use and what's in it, the others on this PC, switching with a restart prompt, the ... menu, and the read-only state.
3. Backups
Every backup with the reason it exists, what's in the one you pick compared with now, Restore, and deleting old backups.
4. Share
One package file with pictures, for another PC. Works without administrator rights.
5. Import
Where a package comes in, with pointers for people who wanted Share or Backups.
6. What will happen
One line per item saying what will happen: device names added or replaced, loopback and host names that clash, a host named after the other PC, a transport that isn't installed, other settings.
7. Done
The result per item, a restart only when something needs one, and Undo this import.

Decided (Pete, October 14, 2026)

  1. Import writes the configuration file, then the MIDI service restarts to use it. It does not go through the running service.
  2. When a package disagrees with this PC, the customer's version wins by default. A loopback or host whose name is taken is left out unless its box is ticked. A host named after the other PC takes this PC's name, ticked by default.
  3. .midiconfigpack is the package file type, and the installer registers it so double-clicking a package opens Import.
  4. Packages carry the port names setting, in its own entry inside the package, outside the configuration file. Never a .reg file.
  5. Backups made by MIDI Settings are full packages: the configuration, its pictures, and settings like port names, with the reason and date inside, so file names stay short.
  6. Global MIDI settings keeps only the name of the configuration in use and Manage configurations once this window exists.
