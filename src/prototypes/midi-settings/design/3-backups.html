  1. Back up now for the configuration in use. The ... menu on the Configurations page backs up any of the others.
  2. Each backup says why it exists: you made it, it was made before an import or a restore, or Windows MIDI Services made it before the first change on that day. The icon says the same thing. Backups made by MIDI Settings are full packages: the configuration, its pictures, and settings that live outside it, like port names. The daily ones from Windows MIDI Services hold only the configuration, and say so.
  3. Picking one shows what's in it next to what's there now, so it's easy to find the one from before things went wrong. Restore asks first (restore), brings back the pictures and settings too, and restarts the MIDI service to use it.
  4. Delete old backups (cleanup) keeps a time window and the newest few of each configuration. Nothing deletes backups by itself, so they pile up until someone does this. One backup can be deleted with the Delete button beside Share.
