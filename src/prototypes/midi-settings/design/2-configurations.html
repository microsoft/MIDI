  1. Four jobs, four pages. Configurations, Backups, Share and Import. This PC's name sits at the bottom, because sharing and importing are about which PC is which.
  2. The one in use comes first. The pencil renames it. Back up now and Share are one click away.
  3. What's in it, in plain counts: device names, pictures, loopbacks, network, Bluetooth and the synthesizer. Never the file itself.
  4. Use this one asks first (switch), because switching restarts the MIDI service, and that drops every app's MIDI connections. Restart later switches anyway and leaves a banner (pending) until the service restarts. Keep using Live set undoes the switch.
  5. The ... menu (menu) has Rename, Duplicate, Back up now, Share and Delete. The one in use can't be deleted.
  6. New configuration starts empty or as a copy of the one in use. This replaces the Create box in Global MIDI settings.
  7. Without administrator rights (noadmin), looking and Share still work. Anything that writes to the configurations folder is gray, Back up now included. Reopen as administrator opens this window again with the rights it needs.
