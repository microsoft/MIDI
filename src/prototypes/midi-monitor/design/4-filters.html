  1. Message types, by UMP message type, the Patchbay's first filter row. SysEx 8 and mixed data share a type, so they share a box.
  2. Channels as 16 buttons, numbered from 1 like everywhere else on screen. "All" turns all 16 back on. In advanced mode this replaces the single Channel picker from simple mode, because a picker can only hold one.
  3. System messages, one box each. Clock and Active Sensing here are the same switches as the two buttons in the status bar, so turning one off in either place shows in both.
  4. Note range, the Patchbay's note filter, for note on, note off, poly pressure and the MIDI 2.0 per-note messages. Everything else ignores it.
  5. A Monitor-only extra: fold repeats. A message with exactly the same data as the one before it from the same source doesn't get a row of its own. It's counted on the row it repeats instead. Useful for controllers that send the same value over and over. Not a Patchbay filter, so it sits below a line. Saved with advanced mode, like the other filters.
  6. The count is on the row, so you can see where repeats were folded and how many. Each one still keeps its own time: Save to File and copy write every folded message out in full, with its own timestamp. Turning the option off brings them back as rows.
  7. The status bar adds up the folded messages, next to Hidden by filter, so the total always matches what was received.
