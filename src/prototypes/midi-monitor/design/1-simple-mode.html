  1. Advanced mode button, beside Settings and Always on top. A toggle, so it stays lit while advanced mode is on. Tooltip: "Advanced mode (Ctrl+Shift+A)". The app opens in whichever mode you used last.
  2. Ctrl+L clears the list from anywhere in the window. It's the shortcut terminals and many logging tools use to clear the screen, and the Monitor has no address bar or other use for it. It goes through the same confirmation as the menu item, so it can't wipe a capture with one stray key press. The menu shows the shortcut, and so do the button tooltips. While we're there, the menu also shows Ctrl+A (the list already handles it), and Ctrl+C is added as "Copy as UMP words", which today has no shortcut.
  3. A Clear button beside Save to File. Today the only way to clear is the right-click menu, which a lot of people never find. Tooltip: "Clear all entries (Ctrl+L)". Turned off when the list is empty, like the menu item.
