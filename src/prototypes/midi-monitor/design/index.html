Windows MIDI Monitor: advanced mode

Comps for a "don't ask me again" on clearing, a clear shortcut, and an advanced mode that watches several groups on several endpoints at once. Simple mode stays as it is. These are HTML: open any page in a browser, or run capture.ps1 for pictures in shots. Nothing here is built. The matching MIDI Patchbay connection monitor is pages 7 and 8 in src\prototypes\midi-patchbay\design.

1. Simple mode, with a clear shortcut
Ctrl+L, a Clear button, and the button that switches modes.
2. Don't ask me again
The clear confirmation, and the setting that turns the question back on.
3. Advanced mode
Sources list with activity lights, a From column, filter chips.
4. Filters
The MIDI Patchbay's filter choices, as a flyout.
5. A narrow window
Sources fold into chips, with an Add flyout.
6. Opened by another app
A command-line launch sets your saved sources aside without changing them.

Questions before building

  1. Activity lights listen to every endpoint. To light up endpoints that aren't checked, the Monitor has to open a connection to each one. That's cheap in Windows MIDI Services, but on a PC with dozens of endpoints it's dozens of connections from one app. Keep it always on, or only while the Sources pane is open?
  2. Ctrl+L for clearing, or something else?
  3. Should simple mode remember the last device (and group and channel) too? It doesn't today.
  4. The "hide repeats" filter on page 4 isn't a Patchbay filter. Keep it, or keep the list exactly the Patchbay's?
  5. Sharing the Patchbay filter code. The Monitor's filters would use the Patchbay's filter type (which is plain code with no UI), moved into the code the tools share, so both apps agree on what each box means.
