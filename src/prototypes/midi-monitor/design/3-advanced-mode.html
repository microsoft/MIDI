3. Advanced mode. The device, group and channel pickers make way for a Sources list on the left: every endpoint, with its groups under it, and a check box on each. Check as many groups on as many endpoints as you like. Each source gets a color, and each row says which source it came from. Filters sit above the list.

  1. Sources: a list, not a dialog. This is my answer to "how does someone pick several groups on several endpoints". A pop-up dialog hides the choice once it's made, and you can't see what's sending while you pick. A list beside the messages is always visible, you change it with one click while listening, and the endpoint check box picks or clears all of its groups at once. Groups use the names from the device's function blocks or group terminal blocks, the same names simple mode's Group picker shows. Endpoint pictures come from MIDI Settings, as they do today. The pane can be resized and hidden (the button at the top), and below about 900 pixels wide it folds into the bar on page 5.
  2. Activity lights. A green dot on every endpoint and group that has sent anything in the last second or so, checked or not. That's how you find which of 40 endpoints your keyboard is really on, without guessing and checking. The switch at the bottom hides everything that isn't sending, so the list shrinks to what matters. Watching the dots means listening to every endpoint, so the Monitor opens each endpoint once whether it's checked or not, and simply doesn't keep unchecked messages. Opening many endpoints is slow on a PC with a lot of devices, so this is a setting: on by default, and off in Settings (page 2). When it's off, only checked endpoints are opened, the dots and the switch go away, and the list shows every endpoint.
  3. Filter opens the panel on page 4, with the same choices as a MIDI Patchbay filter step. Each active rule shows as a chip, and the x on a chip removes that one rule. The badge counts the rules. Filters hide rows; they don't stop the capture, so loosening a filter brings back what it hid (status bar: "Hidden by filter"). The Clock and Active Sensing buttons in the status bar stay, and are the same switches as those two rules.
  4. Order. Rows go in the order the Monitor received them, as today. The other choice is message timestamp, which matters when several sources are involved: a network endpoint can deliver a message a few milliseconds after a USB message that played later. Each row keeps its own timestamp either way.
  5. New From column. A color bar, the endpoint's name and the group, so a row can be read without looking back at the sources. The Group column from simple mode is gone, because From has it. From can be moved or hidden in Edit columns like any other column, and Save to File and copy include it. Simple mode doesn't change: same columns, same pickers, same window.
