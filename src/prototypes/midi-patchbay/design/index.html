MIDI Patchbay, Preview 11 design

Comps for the move from one connection that does everything to processing blocks on the canvas, and from one window to a library plus one editor window per patch. These are HTML: open any page in a browser, or run capture.ps1 for pictures in shots and check.ps1 for a layout check. Nothing here is built.

4. The note filter's own dialog
