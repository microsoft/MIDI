Plain connections stay plain. A connection that filters nothing, changes nothing and has no sending speed is still one line from Out to In.
Blocks come out in the order Patchbay always ran them. Filters first (message types, channels, notes), then channel map, note map, transpose, velocity, aftertouch, control change number, program and bank, control change value, and the throttler last.
Groups stay where they were. The chain starts at the same Out group and ends at the same In group, so a group move works as before.
Only parts that do something become blocks. An untouched filter or transform makes no block. A muted connection becomes a muted first link.
One case needs care. Today a note map is a list of exceptions to the transpose. That converts to a note map, then a transpose, with each mapped note moved back by the transpose amount. A mapped note that would land outside 0 to 127 is listed for the customer to check.
The original is kept. Preview 10 can't read the new format, and would drop the blocks if it saved one, so the first conversion copies the old file into Earlier versions. (Decision for Pete.)
