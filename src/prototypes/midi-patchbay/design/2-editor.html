1
Palette, like MIDI Glass. Filters, transforms and sending are separate sections. Drag a block onto the canvas, or onto a connection to put it in the middle of that connection. Add to patch does the same from the keyboard. The Endpoints tab lists the MIDI endpoints on this PC, and replaces the Add endpoint menu.
2
Blocks don't look like endpoints. One input and one output instead of a row per group, a colored edge for the kind of block (amber filters, violet transforms, green sending), a name, and a line that says what it does right now.
3
Fan in and fan out. Anything can feed a block, and a block can feed anything. The message type filter feeds both note filters. The throttler takes the lower keys and the loopback, and paces them together, because both go to the same synth.
4
"Any group" on the In side. A connection into Any group keeps each message's own group. A connection into a numbered group moves every message onto that group. The Out side still says All groups.
5
The inspector holds one block. Short settings sit right here. Long ones, like the note keyboard or a mapping table, open that block's own dialog. Bypass passes everything through untouched, so a block can be compared with and without.
6
Each patch has its own window. Routing and Start automatically are per patch, at the top. Library brings the library forward. Undo and redo are new, because a patch now has many more pieces to get wrong.
