 How connections are handled. One connection is opened per device when the layout loads, shared by every control and every page, and closed when the layout closes. Group and channel travel in the message, so hundreds of controls on four groups of one device still cost exactly one connection.

The matching rules are the ones Windows MIDI Services already ships. Exact device id, name, USB model or serial number — the same criteria the service configuration and MIDI Patchbay use, so a layout built on one PC has a real chance of finding the right hardware on another. Exact device id is the default because it is unambiguous; the looser rules exist for the day a customer plugs the same keyboard into a different port.

Nothing here blocks playing. A device that is not present does not stop the layout loading, does not stop the other devices working, and does not need to be repaired before the show. The controls that need it say so, and the moment it appears they come back on their own.
