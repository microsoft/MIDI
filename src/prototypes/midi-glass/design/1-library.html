1 Run is the primary action. Pointer, pen or touch on a card reveals Run, Edit and the card menu. Enter runs it, Ctrl+Enter edits it.
2 A missing device never blocks opening. The card names the count, the layout still runs, and the affected controls show as unavailable until it comes back.
3 Thumbnails are drawn from the model, not from a screen capture, so they are correct before the layout has ever been opened on this PC.

Why no file browsing. Every layout lives in Documents › MIDI Layouts as one .midilayout.json file, the same shape MIDI Patchbay uses for patches. The card is the only thing a customer normally touches. Open a file and Show in folder exist for the moment someone is handed a layout by a friend. Thumbnails are cached under %LOCALAPPDATA% and regenerated when the file changes, so the Documents folder stays clean and nothing has to load to draw the grid.
