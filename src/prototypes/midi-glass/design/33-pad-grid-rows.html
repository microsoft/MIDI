"Columns", 6 × 14, chromatic
  • Rows (new): pads run left to right, rows stack bottom to top. A row never wraps into the next one. Rows × Pads per row can go well past 128 (proposed cap 1,024), because the row offset repeats notes on purpose.
  • Columns (new): the same thing turned a quarter turn. Pads run bottom to top, columns stack left to right. Pads per column counts up, and Row offset sets how far each column is from the one to its left.
  • Flow (today's behavior, still the default): a pad count that wraps to fit the width. Existing layouts open unchanged.
  • Pads stretch to fill the control in Rows and Columns, so resizing the control resizes the pads instead of reflowing them. A fixed shape is the point: a hand learns where things are.
  • Everything the grid has today comes along for free: key, scale, In key only, root and scale pickers, note names, colors, glide and per-note bend.
  • Hex pads get the same two arrangements. In Columns the hexagons turn flat side up.
