Screen 13 — the canvas. A layout has a fixed page size chosen from a template, and the editor works on a virtual canvas that is bigger than the page, the way a drawing app does — but with exactly one active area, so there is never any doubt about what will be seen. Growing the canvas asks where the existing controls should sit. Shrinking it offers to scale them. Anything left outside the page is flagged and stays reachable.

Why a virtual canvas rather than a hard edge. The alternative is to clamp every control inside the page, which sounds tidy and is miserable in practice: shrink a page and eleven controls silently pile up along the right edge on top of each other, and there is no undoing that by hand. Letting them sit outside, marked and reachable, means a resize is always reversible — resize back and everything is where it was. The working space is deliberately one area around one page, not an infinite scroll with multiple artboards. There is exactly one thing that gets seen at run time, and the bright rectangle is it.
