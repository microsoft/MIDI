What is happening underneath. Opening this layout opened one connection per endpoint it mentions — three here — not one per control and not one per page. Groups and channels are per binding, so the six mixer strips can all live on one endpoint while the XY pad talks to another. Pointer input goes straight from the control to the send with no data binding in between, and the surface is redrawn by the compositor, so a finger on a fader is never waiting on the UI thread.
