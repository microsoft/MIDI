MIDI Glass — design mockups

A customizable MIDI control surface for Windows, in the Windows MIDI Services tool family. Fourteen screens, plus the design notes in MIDI-Glass-design.md and the sequenced build plan in MIDI-Glass-implementation-plan.md. Start with screen 9 if you want the visual language first, or screen 1 if you want the customer journey.

1Library
What opens when the app starts. Favorites, recents, thumbnails drawn from the layout, Run as the primary action.
2Running a layout, windowed
A six channel mixer, clip pads, XY pad, beat clock and FX, live. WinUI chrome above, the customer's deck below.
3Full screen
Borderless, the fading "press Esc" toast, and a DJ layout in a second theme. Its auto-hide bar is superseded by the corner button on screen 14.
4The editor
Palette, page, inspector, page rail and a live message monitor. Edit and Try are one keystroke apart.
5Arranging and Repeat
Magnetic guides, spacing pills, and the Repeat tool that builds a bank and steps the binding as it goes.
6What a control sends
Three messages, two devices, one control. Learn, feedback binding, and automatic MIDI 2.0 to 1.0 fold-down.
7Sequences
SysEx, notes with a length, waits and a repeat block. Why this is a list and not a script engine.
8Themes
Six hue slots, a deck, control defaults, measured contrast, and a live preview.
9The surface control language
Every control type at rest and in use. The plate, the rim, the light pipe and the bloom.
10Pages, layers and devices
Page order, a shared band, layer keys, and the device table that makes a layout portable.
11Two tonal themes
Pigment Light and Pigment Dark. Flat opaque plates, color carried by a tonal wash instead of a glow. No new rendering layers.
12Bigwig
Raised gray panels, one strong orange, header strips, and a segmented LED ring that costs one element per knob.
13The canvas
Page size templates, the virtual canvas bigger than the page, off-page controls, and the two resize paths.
14Running: scale and chrome
Actual size, fit to screen and custom, saved per layout. Full screen with one corner button instead of a bar.

Serve with pwsh -File serve.ps1 and open http://127.0.0.1:8742/. These files live in src/prototypes/midi-glass/design/ so the design record is versioned. Nothing in that folder ships.
