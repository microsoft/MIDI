Slots, not colors. A control stores "slot 3", never #FFC247. Switch to Neon Booth and every amber control becomes lime together, and the mute buttons still all match. A control can still override with a literal color when it has to, and the theme editor tells you how many controls are using each slot, so you know what a change will touch.

Contrast is measured, not guessed. Each slot is checked against the deck and flagged before it ships to a stage. The High contrast theme is offered, never forced — if Windows switches to a high-contrast theme mid-set, the running layout is left alone and the offer waits until the layout is next opened.
