Screen 16 — Cathode. An old black and white television, which is not black and white. The glass is a dark sour green when nothing is driving it, the phosphor is blue-white, every edge is soft because a beam has no hard edge, and there is no pure black and no pure white anywhere — the darkest color here is #101611 and the brightest is #F4F8FF. What makes it unlike every other theme: a tube has one phosphor, so there is no color to tell one control from another with. That turns out to be the whole design.

What the numbers said. The widest pair of slots here is 2.32:1 and the closest adjacent pair is 1.10:1. Three is the least anyone needs to read two things apart, so nothing on this theme can be color coded. The slots stay six, because the model has six and a layout has to keep working when the theme is switched — they simply stop carrying meaning.

The box does not separate itself. A raster box measures 1.12:1 against the middle of the glass. Bone had the same problem and answered it with a shadow; a tube answers it the other way round, with the light it spills. Turn the glow off and the layout disappears into the screen, so a theme editor should refuse to let it reach zero here.

Two colors were not chosen. #92A7BE is the dimmest slot because it is where a label on a raster box lands at exactly 4.53:1 — one step lower and the text fails. And the palette runs from #101611 to #F4F8FF and no further, because a true black is a hole cut in the glass and a true white is a sheet of paper. Swept over the whole deck, the darkest pixel on the screen is #060B08, where a scan line crosses a carved slot in a corner. Still green. Still not black.

Free — what Cathode reuses

The same tonal machinery as Pigment, Bigwig and Bone with the hue wash off, the six slots, the track color, corner rounding and the value strip. The deck is already a radial gradient lit from the middle, so the corner falloff is the existing deck brush with different stops. Inverse video costs nothing at all — a filled plate with a dark label is exactly what the tonal themes already do for on. No new control types and no new shapes.

Three additions — what it needs

Scan lines: one overlay for the whole deck, never anything per control, so eighty controls cost the same as four. It has to be drawn in device pixels after the page is scaled, or a layout at 87 % turns a 3 px pitch into a beat pattern across the screen. A white light source, which Bone already asked for. And a resting glow level separate from the activity glow, because on this theme every lit thing spills a little all the time. The masked shadow that draws it is already there.

Three things the measurement decided

No two slots reach 3:1, so color coding is off the table and the theme picker has to say so. The dimmest slot is #92A7BE because one step lower fails 4.5:1 for a label. And the box sits at 1.12:1 against the glass, which is why the glow is structure rather than decoration — a theme editor should refuse to let it go to zero here, the same way it should refuse to flatten Bone's shadow.

Panic is the test of this. The full screen rule already says Panic sits last, keeps its color and never moves. On every other theme the color is doing most of that work and the position is a backstop. Here the position is all there is, which is a good argument that the rule was right to begin with. One motion, and it is optional. The obvious flourish is a tube warming up when a layout opens — a bright line that opens into a picture. It is lovely once and tiresome by the fourth time, it delays the first thing a performer wants to touch, and it is exactly the kind of thing the Windows reduced motion setting exists to stop. So: off by default, a per-layout switch, and never on a page change. No roll, no flicker, no jitter at any setting; a surface somebody has to hit accurately must not move on its own. Where this theme belongs. A dark room, and a page that does not lean on color — a transport, a clip grid, a row of faders. On a hundred-and-twenty-control page where color is what stops two knobs being confused, Studio Dark still wins, and Cathode will make that page harder to play. Two rules it keeps. A control still never uses more than one color, and that color still only appears on the rim, the value and the fill. It is just that here, for the first time, every control has the same one.
