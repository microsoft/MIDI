Full screen is a presentation mode, not a different app. F11 or the button flips it; the surface keeps running and nothing reconnects. The toast fades after about two and a half seconds and never comes back unless the pointer leaves and returns. On a tablet there is no Esc key, so the same bar slides down from the top edge on a swipe or a tap in the top strip, and it carries Panic. While a layout is running full screen the app holds a display required request, so a performer's screen never blanks mid-set. Which display it opens on is remembered per layout.
