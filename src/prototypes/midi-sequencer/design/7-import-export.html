Export writes MIDI 2.0 clip files (the format MIDI 2.0 calls SMF2), Standard MIDI Files or DAWproject, for one clip, some tracks or the whole sequence, and says up front what a format can't hold.

ResolutionVelocity and controllers keep their MIDI 2.0 detail.
  1. Standard MIDI Files come in track by track, each as a clip on a new track (or on the selected track). The file's tempo is used when the sequence has none, its markers become tags, and its copyright text stays with the clips it came from.
  2. Captures from MIDI Monitor and the console. A CSV capture keeps exact times and MIDI 2.0 messages, so a jam you captured becomes a clip that plays back just as it happened. One track per group.
  3. Paste. Messages copied in MIDI Monitor paste straight into a clip. They have no times, so you choose how to lay them out.
  4. MIDI 2.0 clip files keep everything the sequence can hold. Whole-sequence export writes one per track until the MIDI Container File is published.
  5. Standard MIDI Files are still the way to reach most other software. The dialog counts what would be lost before you export, instead of after.
  6. Chance and generators export as the notes they play, from their saved seeds, so the file matches what you heard from bar 1.
  7. DAWproject is the open format Bitwig Studio, Cubase, Studio One and others use to move a song between apps. It keeps folders, clips, scenes and markers, which a Standard MIDI File can't. It has no MIDI devices, so import asks where each track plays.
