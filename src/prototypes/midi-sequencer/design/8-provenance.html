  1. The same block as MIDI Glass and MIDI Patchbay. Author, organization, web page, license, created, the tool that made it, and how it was made, in the same words, so one author profile fills all three.
  2. A suggestion, not a verdict. The app knows which clips were recorded, drawn, generated, imported or written by an assistant, so it can suggest how the whole project was made. You choose.
  3. Clip by clip. Every clip remembers how it began. An imported clip keeps its file name and copyright text, which is what you need before you share or sell a piece that uses it.
  4. AI help is labeled. A clip written by an AI assistant says so, and records whether a person checked it, using the same AI disclosure terms as the other tools.
  5. What reaches an exported file. MIDI 2.0 clip files carry project name, clip name, composer and copyright as standard messages, and a Standard MIDI File carries the copyright and names as text. The full record stays in the project.
